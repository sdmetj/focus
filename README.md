# FOCUS

지금 집중할 **한 가지**와 **매일 루틴**만 남긴 미니 웹앱. 아이폰 사파리에서 '홈 화면에 추가'하면 앱처럼 열립니다.

## 구성
- `index.html` — 앱 전체(HTML/CSS/JS 단일 파일, 외부 CDN 없음)
- `manifest.webmanifest`, `icons/` — PWA 메타·아이콘(✦ 심볼)
- `sw.js` — 오프라인 캐시(HTML은 네트워크 우선, 캐시 버전 `focus-v17`)
- 데이터는 브라우저 `localStorage`에만 저장
  - `focus.v1` — 오늘의 상태(목표·대기열·루틴·오늘 완료). 목표는 `{ text, mode: 'task'|'timer', minutes, endsAt, remainMs, paused }`
  - `focus.composeMode` / `focus.composeMinutes` — 마지막으로 고른 과업/몰입과 몰입 시간(기본 25분)
  - `focus.history.v1` — 날짜별 기록 `{ "YYYY-MM-DD": { focusDone, routinesDone, routineTotal } }`
  - `focus.lang` / `focus.sound` — 언어(`ko` / `ja`)·효과음 설정
  - `focus.gacha.v1` — 별 스킨 상태 `{ tickets, shards, owned[], equipped, rin, v2, … }`
  - `focus.rpg.v1` — 성좌 토벌 상태 `{ exp, cleared[], day: { date, used, routineExp[] } }`
  - `focus.sanctuary.v1` — 방치형 성역 `{ slots, deploy[], buildings{beacon,altar,turret,garden}, levels{ id: {lv,xp} }, lastTick, kills, frac, day }`
  - `focus.break.v1` / `focus.mini.v1` — 미니게임 최고 기록·일일 보상
  - `focus.seenVersion` — 마지막으로 본 업데이트 안내 버전

## 메인 화면
- 상단: 동시에 **1개**만 표시되는 '지금의 FOCUS' 슬롯 + 완료/수정/비우기, 접힌 '다음 대기열' 서랍
- **과업 / 몰입 두 형식** — 시작할 때 「과업」과 「몰입」 중 고름
  - 과업: 텍스트 목표만 적고 완료 버튼으로 달성(기존 방식)
  - 몰입: 목표 + 시간(15·25·45·60분 프리셋 또는 1~180분 직접 입력). 메인 카드가 `MM:SS` 실시간 카운트다운 + 진행 바
  - 타이머는 **일시정지 / 재개 / 조기 완료**. `00:00`이 되면 종소리·진동·`00:00` 연출 뒤 과업 완료와 같은 보상(별조각·뽑기권·기록)이 들어옴
  - 남은 시간은 `endsAt` 타임스탬프 기준이라 새로고침·백그라운드 복귀에도 어긋나지 않고, 자리를 비운 사이 끝났으면 돌아오자마자 완료 처리
  - 완료 기록에는 `mode`·`minutes`가 남아 캘린더에 `몰입 25분`으로 표시됨
- 하단: '매일 루틴' 5종 기본 탑재, 탭 체크, `n/5` 진행률, 추가·수정·삭제
- 날짜가 바뀌면 체크 상태만 자동 초기화되고, 전날 기록은 `focus.history.v1`에 남음
- 헤더의 `KR | JP` 토글 — UI 문구와 기본 루틴 5종이 일본어로 전환
- 헤더의 날짜 버튼 → 월간 캘린더 모달
- **장착 스킨 테마** — 스킨의 색·등급에 맞춰 배경 그라데이션·카드 테두리·글로우가 바뀜(500종 전부)
- 하단 `✎ 업데이트 내역` — v1.4.0 → v2.0.0 변경 내역 누적 열람
- **오른쪽 가장자리 리퀴드 글라스 탭** — 탭하거나 꾹 누르면 `✦ 별의 세계`가 열림 (상단 `✦ FOCUS` 로고도 동일)

## ✦ 별의 세계
세 카테고리로 나뉩니다.

### 1) 뽑기 · 도감
- **별 스킨 500종** = 기존 100종(id·색 그대로) + 시리즈×무드 399종 + 스페셜 1종
  - 기존: 기본 1 · 커먼 40 · 레어 30 · 에픽 19 · 레전더리 10
  - 신규: 21 시리즈(벚꽃·바다·겨울·별·음악 …) × 19 무드(미스트·세레나데·프리즘 …)
  - 등급 확률: 커먼 45% · 레어 35% · 에픽 15% · 레전더리 5% (등급 안에서 균등)
- 도감: 수집률(%) 바 · 필터 `전체·보유·미보유·커먼·레어·에픽·레전더리·스페셜` · 이름/시리즈 검색 · 60개씩 더 보기
- 보유 스킨 탭 → 즉시 장착 / 중복 → **별조각 +7**
- 교환: **별조각 20개 → 뽑기권 1장**, 200개 → 10장
- **도감 시너지(영구)** — 보유 수·등급 수집·스킨 레벨 합산으로 공격력·치명타·방치 별조각·토벌 피해 보너스
- **린 캣(`rin_cat`)** — 하늘색 고양이 픽셀 스킨. 도감 탭 배너에서 생일 퀴즈(10월 9일 / 10/9 / 1009 / 10月9日 …)를 풀면 해금, 일반 뽑기에는 나오지 않음

### 2) RPG
- **방치형 성역**
  - `<canvas>`에서 편성한 별이 스스로 적을 사냥(개별 이동·사격·분리)
  - 출전 슬롯 3 → 최대 10 (별조각으로 확장)
  - 건물 4종: 별빛 등대(수급 +12%/Lv) · 에테르 제단(스킨 경험치 +15%/Lv) · 유성 포탑(공격력 +14%/Lv) · 성운 정원(수급 +9%/Lv) — 캔버스에 그려지고 탭하면 발동
  - 편성 스킨은 **성역·성좌 공유 레벨**을 쓴다. Lv.5 공격력 +3% · Lv.10 치명타 +2% · Lv.20 별조각 +5%
  - **자동 스킬 이펙트** — 기본 공격은 빛 궤적 + 착탄 스파크, 등급별 필살기는 레어 충격파 링 · 에픽 유성우 · 레전더리 성운 번개 · `rin_cat` 하늘색 발바닥 폭죽(`#7dd3fc`). 적중 시 `+1`/`CRIT!`/`METEOR!`/`CHAIN!`/`NYA!` 팝업, 별을 탭하면 그 별의 스킬이 즉시 발동
  - 이펙트·파티클 배열 상한(`fx 32 · parts 220 · pops 16`)으로 iOS Safari 프레임 보호, 별 광채는 `shadowBlur` 대신 레이어드 글로우
  - 별조각 수급은 시간당(초반 2.2/h)으로 시작해 슬롯·건물·레벨·시너지가 오르면 커짐. **오프라인 최대 24시간 정산**
- **성좌 토벌** — 하루 도전권 2회, 보스 24단계(황도·심연·시간·별자리 4계열). FOCUS 완료 +20 EXP · 루틴 체크 +10 EXP · 승리 시 `30 + 단계×5` EXP, 스킨 등급·패시브·필살기에 공유 레벨과 도감 시너지가 더해짐
  - 보스마다 고유 색·아이콘·필살 스킬(3턴마다 발동: 강타 · 방어 무시 · 흡혈 · 2연격 · 폭발)·추천 레벨
  - 뒤쪽 보스일수록 첫 처치 뽑기권(19단계부터 2장)·별조각 보상이 큼
  - **성역 ↔ 토벌 레벨·경험치 공유** — `focus.rpg.v1`의 `exp` 하나가 공통 성장치. 성역 사냥·제단·오프라인 정산, 토벌 승리, FOCUS·루틴이 모두 같은 경험치로 들어가고, 기존 사용자는 성역 별 레벨과 토벌 레벨 중 높은 쪽으로 1회 마이그레이션

### 3) 미니게임
- **별빛 벽돌깨기** — 조준 발사·2배속·공 회수, +1 오브로 공 증가, 레전더리 능력(관통/폭발/광선/위성)
- **메테오 닷지** — 드래그로 별을 움직여 운석 회피·별조각 수집
- **오빗 타이밍** — 궤도 빛점이 목표와 겹칠 때 탭, 콤보
- **별자리 기억** — 별 순서 기억 후 재현
- 모두 장착 스킨 색 연동 · Web Audio 효과음(🔊/🔇) · KR/JP · 일일 보상

## 업데이트 안내
- `APP_VERSION`(현재 `2.1.0`)과 `CHANGELOG`를 고치면, 접속 시 `focus.seenVersion`과 다를 때 한 번만 `✦ FOCUS 업데이트` 팝업이 뜹니다.
- `CHANGELOG`는 버전별로 쌓이므로 하단 `업데이트 내역`에 v1.4.0부터 누적 표시됩니다.
- 버전이 바뀌면 `focus.gacha.v1`의 `giftVersion`이 이전 버전이므로 **업데이트 보상 뽑기권 +10장**이 자동 지급됩니다(같은 버전에서 중복 없음).
