# FOCUS

지금 집중할 **한 가지**와 **매일 루틴**만 남긴 미니 웹앱. 아이폰 사파이에서 '홈 화면에 추가'하면 앱처럼 열립니다.

## 구성
- `index.html` — 앱 전체(HTML/CSS/JS 단일 파일, 외부 CDN 없음)
- `manifest.webmanifest`, `icons/` — PWA 메타·아이콘(✦ 심볼)
- `sw.js` — 오프라인 캐시(HTML은 네트워크 우선)
- 데이터는 브라우저 `localStorage`에만 저장
  - `focus.v1` — 오늘의 상태(목표·대기열·루틴·오늘 완료)
  - `focus.history.v1` — 날짜별 기록 `{ "YYYY-MM-DD": { focusDone, routinesDone, routineTotal } }`
  - `focus.lang` — 선택 언어(`ko` / `ja`)
  - `focus.gacha.v1` — 별 스킨 뽑기 상태 `{ tickets, shards, owned[], equipped, lastTicketDate }`

## 기능
- 상단: 동시에 **1개**만 표시되는 '지금의 FOCUS' 슬롯 + 완료/수정/비우기, 접힌 '다음 대기열' 서랍
- 하단: '매일 루틴' 5종 기본 탑재(기상 후 세안·점심 후 양치·영양제·일기/성경·독서), 탭 체크, `n/5` 진행률, 추가·수정·삭제
- 이전 기본 4종을 그대로 쓰던 `localStorage`는 새 기본 5종으로 자동 이전(직접 고친 목록은 유지)
- 날짜가 바뀌면 체크 상태만 자동 초기화되고, 전날 기록은 `focus.history.v1`에 남음
- 헤더의 `KR | JP` 토글 — UI 문구와 기본 루틴 5종이 일본어로 전환(직접 고친 루틴은 그대로). 선택은 `focus.lang`에 저장
- 헤더의 날짜 버튼 → 월간 캘린더 모달(`‹`/`›` 월 이동, 오늘 강조, 기록 있는 날 흰 점) → 날짜를 탭하면 그날 완료한 FOCUS와 루틴 달성(`3/5`) 표시

## ✦ 별 스킨 뽑기 & 도감
- 상단 좌측 `✦ FOCUS` 로고를 탭하면 **별 스킨 모달**이 열립니다. 메인 화면 버튼은 추가하지 않았고, 뽑기권이 1장 이상이면 `✦` 옆에 작은 흰 점이 붙습니다.
- 스킨 18종: `모노 화이트`(기본 보유)
  - 커먼 5종: `실버 미스트`, `애쉬 스파클`, `스카이 블루`, `민트 그린`, `라벤더`
  - 레어 5종: `페일 블루`, `로즈 쿼츠`, `코랄 핑크`, `레몬 앰버`, `네온 펄스`
  - 에픽 4종: `골드 스타`, `오빗 링`, `스타더스트`, `스노우 크리스탈`
  - 레전더리 3종: `오로라 프리즘`, `크레센트 문`, `미드나잇 아우라`
  - 등급 확률: 커먼 45% · 레어 35% · 에픽 15% · 레전더리 5% (등급 안에서 균등)
- 이펙트: 은은한 숨쉬기/글로우, 궤도 링 회전(`오빗 링`), 미니 별가루(`스타더스트`), 결정 광채(`스노우 크리스탈`), 초승달(`크레센트 문`), 오로라 그라데이션(`오로라 프리즘`). `미드나잇 아우라`는 장착 시 상단 배경과 FOCUS 카드 테두리까지 밤하늘 블루로 물듭니다.
- 뽑기권: 첫 접속 시 웰컴 1장 지급. 그날 루틴을 **전부** 체크하면 하루 1회 `+1` (`lastTicketDate`로 중복 지급 방지).
- 중복 스킨은 **별조각 +1**, 별조각 3개를 뽑기권 1장으로 교환할 수 있습니다.
- 보유 스킨을 탭하면 즉시 장착되어 상단 `✦`와 FOCUS 카드 `✦` 태그에 스킨 색·글로우·반짝임이 적용됩니다(미장착 시 기본 무채색).
- 모든 문구는 `KR | JP` 전환에 맞춰 함께 바뀝니다.

## 새로고침
- 푸터의 `↻ 새로고침` — 서비스 워커 업데이트를 확인한 뒤 `location.reload()`로 최신 화면을 불러옵니다. 저장 데이터(`localStorage`)는 유지됩니다. (홈 화면 PWA 모드에는 당겨서 새로고침이 없습니다)

## 업데이트 안내
- `index.html`의 `APP_VERSION`(현재 `1.4.0`)과 `CHANGELOG`만 고치면, 접속 시 `focus.seenVersion`과 다를 때 한 번만 `✦ FOCUS 업데이트` 팝업이 뜨고 `확인`을 누르면 해당 버전이 저장됩니다.
