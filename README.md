# FOCUS

지금 집중할 **한 가지**와 **매일 루틴**만 남긴 미니 웹앱. 아이폰 사파리에서 '홈 화면에 추가'하면 앱처럼 열립니다.

## 구성
- `index.html` — 앱 전체(HTML/CSS/JS 단일 파일, 외부 CDN 없음)
- `manifest.webmanifest`, `icons/` — PWA 메타·아이콘(✦ 심볼)
- `sw.js` — 오프라인 캐시(HTML은 네트워크 우선, 캐시 버전 `focus-v10`)
- 데이터는 브라우저 `localStorage`에만 저장
  - `focus.v1` — 오늘의 상태(목표·대기열·루틴·오늘 완료)
  - `focus.history.v1` — 날짜별 기록 `{ "YYYY-MM-DD": { focusDone, routinesDone, routineTotal } }`
  - `focus.lang` — 선택 언어(`ko` / `ja`)
  - `focus.gacha.v1` — 별 스킨 상태 `{ tickets, shards, owned[], equipped, lastTicketDate, focusTicketDate, focusTicketCount, streakLast, ticketStreak, giftVersion }`
  - `focus.rpg.v1` — 성좌 토벌 상태 `{ exp, cleared[], day: { date, used, routineExp[] } }`
  - `focus.seenVersion` — 마지막으로 본 업데이트 안내 버전

## 메인 화면 (v1.5에서도 그대로)
- 상단: 동시에 **1개**만 표시되는 '지금의 FOCUS' 슬롯 + 완료/수정/비우기, 접힌 '다음 대기열' 서랍
- 하단: '매일 루틴' 5종 기본 탑재, 탭 체크, `n/5` 진행률, 추가·수정·삭제
- 날짜가 바뀌면 체크 상태만 자동 초기화되고, 전날 기록은 `focus.history.v1`에 남음
- 헤더의 `KR | JP` 토글 — UI 문구와 기본 루틴 5종이 일본어로 전환. 선택은 `focus.lang`에 저장
- 헤더의 날짜 버튼 → 월간 캘린더 모달

## ✦ 허브 모달 (상단 `✦ FOCUS` 로고 탭)
메인 화면에는 새 버튼을 추가하지 않고, 로고를 탭하면 열리는 시트 안에서 두 탭으로 나뉩니다.

### 1) 뽑기 · 도감
- **별 스킨 100종** = 기본 `모노 화이트` 1종 + 뽑기 99종
  - 커먼 40종 · 레어 30종 · 에픽 19종 · 레전더리 10종
  - 등급 확률: 커먼 45% · 레어 35% · 에픽 15% · 레전더리 5% (등급 안에서 균등)
  - 기존 v1.4의 18종 id(`mono`, `silver`, `ash`, `sky`, `mint`, `lavender`, `blue`, `rose`, `coral`, `amber`, `neon`, `gold`, `orbit`, `stardust`, `snow`, `aurora`, `crescent`, `midnight`)와 색·광채·이펙트는 그대로 유지
  - 신규 82종은 `id`별 CSS 변수(`--star`/`--star-glow`)와 모션(숨쉬기·반짝임·글로우·흔들림·부유·오로라)으로 구분
- 도감 상단: 수집률(%) 바 + 필터 `전체 · 보유 · 미보유 · 커먼 · 레어 · 에픽 · 레전더리`
- 보유 스킨 탭 → 즉시 장착(상단 `✦`, FOCUS 카드 태그, 성좌 토벌 화면에 반영)
- 중복 → 별조각 +1, 별조각 3개 → 뽑기권 1장 교환

### 2) 성좌 토벌 (RPG)
- 현실의 집중이 EXP: **FOCUS 완료 +20**, **매일 루틴 체크 +10**(해제 시 회수)
- 별 레벨이 오르면 기본 공격력·체력이 상승 (레벨업 곡선 `80 + (Lv-1)×40` EXP)
- **하루 도전권 2회**(자정 초기화), 보스 12단계 순차 해금: 잡념의 그림자 → 미룸의 거인 → 야근의 성좌 → … → 성좌의 군주
- 턴제 전투(공격 / 필살기 / 방어), 한 판 10초 내외. 처치 시 **첫 클리어 뽑기권 +1 · 별조각 +2**, 재도전은 별조각 +1
- 스킨 등급 연동
  - 커먼 +2% · 레어 +5% · 에픽 +4% · 레전더리 +8% 공격력 보너스
  - **에픽 19종**: 패시브(치명타·피해 감소·최대 체력·별조각 추가·매 턴 회복 등)
  - **레전더리 10종**: 고유 필살기 — 프리즘 버스트 · 월식 베기 · 심야의 일격 · 불사조 강림 · 성좌 관통 · 영원의 빛 · 군주의 포효 · 심연 개방 · 세라핌 윙 · 창세의 빛
- 현재 장착 스킨과 그 스킬/패시브를 토벌 화면 상단·전투 화면에 표시

## 뽑기권 수급
| 경로 | 지급 |
| --- | --- |
| 업데이트 보상 (버전당 1회) | +10장 |
| 지금의 FOCUS 완료 | +1장 (하루 최대 3장) |
| 매일 루틴 100% | +1장 (하루 1회) |
| 연속 달성 | 3일 +2장 · 7일 +5장 |
| 성좌 토벌 첫 클리어 | +1장 |
| 별조각 3개 교환 | +1장 |

## 업데이트 안내
- `APP_VERSION`(현재 `1.5.0`)과 `CHANGELOG`만 고치면, 접속 시 `focus.seenVersion`과 다를 때 한 번만 `✦ FOCUS 업데이트` 팝업이 뜹니다.
- 버전이 바뀌면 `focus.gacha.v1`의 `giftVersion`이 이전 버전이므로 **업데이트 보상 뽑기권 +10장**이 자동 지급되고 팝업에 표시됩니다(같은 버전에서 중복 지급 없음).
